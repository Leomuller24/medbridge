# MedBridge first screen

## What I’ll build
- Replace the empty page with a professional desktop workspace for cultural context and phrase translation.
- Add a compact sidebar, a context selection area, communication guidance, cultural notes, and a practical phrase list.
- Clearly label all content as demonstration data and keep the safety boundary visible without making the interface feel alarming.

## Design
- Use a calm blue-and-white system, one clean sans-serif font, rounded cards, generous spacing, and restrained shadows.
- Keep the information dense enough for clinicians to scan quickly, while preserving clear hierarchy and accessibility.
- Adapt gracefully to narrower screens while prioritizing the requested desktop experience.

## Technical details
- Use static mock content only, with no persistence, uploads, patient fields, or external services.
- Use existing React, Tailwind, and interface controls; add only small local components where needed.
- Add page-specific metadata and verify the finished screen in the browser.
