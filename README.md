# MedBridge

We are building MedBridge, a web app that gives Swiss healthcare providers cultural and communication context when treating migrant patients. It is informational and translation-oriented, and it never diagnoses or gives medical advice. Use a calm blue and white palette, one font, rounded cards, generous spacing, and a professional desktop-website look. Use mock data only. Do not collect or store real patient information. Keep the interface in English for now. Do not add features I have not asked for.
